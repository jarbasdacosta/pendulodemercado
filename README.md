# Pêndulo de Mercado

**Entre o pânico e a euforia, onde o mercado está.**

Leitura diária do Ibovespa: o quanto o preço está esticado em relação à própria tendência
(IMA Wavelet), risco de bolha e de antibolha (LPPL), amplitude do mercado, capital estrangeiro
e sinais de topo e fundo. Publicado em
[jarbasdacosta.github.io/pendulodemercado](https://jarbasdacosta.github.io/pendulodemercado).

## Como funciona

As páginas não são escritas à mão: são geradas por scripts Python que rodam num servidor
próprio durante o pregão (a cada 15 minutos) e no fechamento. Este repositório guarda apenas o
resultado em Markdown, que o [Quartz](https://quartz.jzhao.xyz) compila em site estático pelo
GitHub Actions a cada envio.

Conteúdo educacional baseado em estatística de 26 anos. Não é recomendação de investimento.
